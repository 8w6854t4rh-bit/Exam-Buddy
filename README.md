# Exam-Buddy
Prüfungstrainer für Automobilkaufleute: über 300 Karteikarten, über 100 Quizfragen im WiSo-Stil, Rechenaufgaben mit immer neuen Zahlen und Rechenweg, Buchungssätze im T-Konto zum Ziehen sowie Formelsammlung und Lernfelder kurz und knapp. Mit Lernstand, ohne Anmeldung. Eigene Aufgaben, orientiert an den IHK-Abschlussprüfungen.
